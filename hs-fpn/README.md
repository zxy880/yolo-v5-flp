# 小目标检测增强模块 (HFP & SDP) 实现指南

本项目复现了针对 FPN (Feature Pyramid Network) 改进的两个核心模块：**高频感知模块 (HFP)** 和 **空间依赖感知模块 (SDP)**。这两个模块旨在提升小目标检测的性能，且设计为“即插即用”的轻量级组件。

为了方便迁移到不同的检测框架（如 MMDetection, YOLO 等），本文档详细说明了模块的核心原理、输入输出规格以及对动态特征图尺寸的处理机制。

## 模块一：高频感知模块 (HFP)

**High-Frequency Perception Module**

### <a id="核心原理-hfp"></a>核心原理

小目标的信息往往隐藏在图像的高频部分（边缘、纹理），而背景通常对应低频部分。HFP 模块通过以下步骤增强小目标特征：

1.  **高频提取 (DCT/IDCT)**:
    *   利用 2D 离散余弦变换 (DCT) 将特征图转换到频域。
    *   应用高通滤波器（掩码），滤除左上角的低频分量（由参数 `alpha` 控制，默认 0.25，即滤除前 25% 的低频区域）。
    *   通过逆 DCT (IDCT) 还原回空间域，得到仅包含高频细节的特征图。

2.  **通道路径 (Channel Path)**:
    *   为了捕捉通道间的依赖关系，将高频特征图通过自适应池化 (`AdaptiveAvgPool` 和 `AdaptiveMaxPool`) 压缩到固定的 $k \times k$ (默认 $16 \times 16$) 尺寸。
    *   **关键点**：这里固定尺寸是为了防止小目标在全局池化中信息完全丢失，同时保证计算量可控。
    *   通过分组卷积生成通道权重，并广播回原始尺寸进行加权。

3.  **空间路径 (Spatial Path)**:
    *   通过 $1 \times 1$ 卷积和 Sigmoid 激活生成空间注意力图，聚焦于高频响应强烈的区域。

### <a id="动态尺寸适应性-hfp"></a>动态尺寸适应性

HFP 模块天然支持任意尺寸的输入特征图 ($H \times W$)，迁移时**无需修改代码**。

*   **DCT 变换**: 是基于整个特征图进行的全局变换，不依赖固定尺寸。
*   **池化层**: 使用了 `nn.AdaptiveAvgPool2d((k, k))`。无论输入特征图是 $100 \times 100$ 还是 $800 \times 600$，都会被临时压缩到 $16 \times 16$ 进行通道权重的计算。
*   **广播机制**: 计算出的通道权重 ($C \times 1 \times 1$) 和空间权重 ($1 \times H \times W$) 会自动广播并应用到原始尺寸的特征图上。

## 模块二：空间依赖感知模块 (SDP)

**Spatial Dependency Perception Module**

### <a id="核心原理-sdp"></a>核心原理

在 FPN 中，上层特征（如 P4）上采样后与下层特征（如 P3）融合时，往往存在空间对齐误差。SDP 引入了**分块像素级交叉注意力**来解决这个问题。

1.  **Q/K/V 生成**:
    *   Query (Q): 来自当前层特征 (如 P3)。
    *   Key (K) & Value (V): 来自上层上采样后的特征 (如 P4_upsampled)。

2.  **特征分块 (Feature Partitioning)**:
    *   为了降低全局 Attention 的计算复杂度，将特征图划分为多个小块 (Block)。
    *   块的大小 (Block Size) 强制与顶层特征图 ($C_5$) 的尺寸一致（默认为 $25 \times 20$，可视具体数据集调整）。
    *   假设输入特征图尺寸为 $H \times W$，块大小为 $h_{b} \times w_{b}$，则图像被分为 $N = (H/h_b) \times (W/w_b)$ 个块。

3.  **块内交叉注意力**:
    *   在每个块内部计算 Q 和 K 的相关性，生成注意力矩阵，然后作用于 V。
    *   这使得模块能够学习下层特征与上层特征之间的精细空间依赖关系。

### <a id="动态尺寸适应性与约束-sdp"></a>动态尺寸适应性与约束

**注意：SDP 模块对输入尺寸有特定的整除性约束。**

在迁移或集成时，必须确保 FPN 各层的特征图尺寸满足倍数关系。

*   **分块逻辑**: 代码通过 `view` 和 `permute` 操作将 $H \times W$ 的特征图重排为 $N$ 个 $h_{block} \times w_{block}$ 的块。
*   **尺寸约束**: 输入特征图的高度 $H$ 和宽度 $W$ **必须** 分别能被块尺寸 `c5_size` (默认 $25 \times 20$) 整除。
    *   例如：如果 `c5_size=(25, 20)`，那么 P3 的尺寸通常应该是 P5 的 4 倍，即 $100 \times 80$，这是可以整除的。
    *   **迁移建议**: 如果你的网络输入尺寸变化较大（如多尺度训练），请确保 Input Size 经过下采样后（通常是 stride=32 到 P5），P5 的尺寸即为 `c5_size`。或者，你在初始化 SDP 时，传入当前数据集典型的 P5 特征图大小。

如果遇到尺寸不匹配报错（如 `RuntimeError: shape '...' is invalid for input of size ...`），请检查：
1.  输入图片尺寸是否是 $32 \times \text{BlockSize}$ 的倍数。
2.  或者修改 `SDP` 初始化时的 `c5_size` 参数，使其适配当前的特征图尺寸。

## 快速开始

### 文件结构
*   `modules.py`: 包含 `HFP` 和 `SDP` 类的完整实现。
*   `test_modules.py`: 简单的测试脚本，用于验证维度。

### 使用示例

```python
import torch
from modules import HFP, SDP

# ==========================================
# 1. HFP 使用示例 (通常用于 P2, P3 层)
# ==========================================
# 假设当前特征图为 P3，通道 256，尺寸 100x80
feat_p3 = torch.randn(1, 256, 100, 80)

# 初始化 HFP
# alpha: 高频滤波器阈值 (0.25)
# k: 通道注意力池化尺寸 (16)
hfp_module = HFP(in_channels=256, alpha=0.25, k=16)

# 前向传播
enhanced_p3 = hfp_module(feat_p3)
print(f"HFP Output Shape: {enhanced_p3.shape}") # Should be (1, 256, 100, 80)


# ==========================================
# 2. SDP 使用示例 (用于特征融合阶段)
# ==========================================
# 假设 C5 (P5) 的尺寸为 25x20 (基于输入 800x640, stride 32)
c5_h, c5_w = 25, 20

# 当前层 Ci (如 P3), 尺寸是 P5 的 4 倍 -> 100x80
feat_ci = torch.randn(1, 256, 100, 80)

# 上一层上采样后的特征 Pi+1 (如 P4 upsampled), 尺寸需与 Ci 一致
feat_pi_plus_1 = torch.randn(1, 256, 100, 80)

# 初始化 SDP
# 注意：c5_size 决定了分块的大小。
# 必须保证 feat_ci 的 H 能被 c5_h 整除，W 能被 c5_w 整除。
sdp_module = SDP(in_channels=256, c5_size=(c5_h, c5_w))

# 前向传播
fused_feature = sdp_module(feat_ci, feat_pi_plus_1)
print(f"SDP Output Shape: {fused_feature.shape}") # Should be (1, 256, 100, 80)
```

## 常见问题 (FAQ)

**Q: 如果我的输入图片大小不是固定的怎么办？**
A:
*   **HFP**: 完全不受影响。
*   **SDP**: 需要小心。SDP 依赖于特征图能被切分成整数个块。如果你的推理过程图片尺寸是任意的（非 32 的倍数），建议在送入网络前进行 `pad` 操作，使其长宽均为 32 的倍数（这是大多数检测网络的标准做法）。只要长宽是 32 的倍数，且 `c5_size` 设置为 `(H/32, W/32)`，或者你固定 `c5_size` 为一个较小的公约数（如 `(1, 1)` 即退化为全局 Attention，但计算量巨大；或者 `(8, 8)`），就能保证运行。
*   **最佳实践**: 在初始化 `SDP` 时，将 `c5_size` 设置为训练时 P5 层的典型尺寸，并确保输入图像经过 Padding 后能保持各层级尺寸的倍数关系。

**Q: 为什么 HFP 里要用 DCT？**
A: 小目标的特征在空间域很容易被淹没，但在频域的高频部分往往能保留清晰的边缘信号。DCT 是一种高效的频域分析工具，且计算过程完全可导，适合嵌入神经网络。
